## 2026-11-28 Edge 桌面重開與續驗

環境：Windows 11、Microsoft Edge 桌面視窗、本機服務 `127.0.0.1:8000`。先查到 8000 埠沒有監聽程序；不是瀏覽器權限提示。重開服務後，HTTP 首頁回 200，教師頁與學生頁可載入，未見需要授權的提示。舊頁面的學生憑證在老師釋放後已失效；直接用舊狀態選第 50 組會顯示「邀請碼不正確」。依教師頁當下顯示的邀請碼重新加入後，學生頁顯示「第50組／準備中」。

桌面 UI 檢查：教師端組數為 50、組隊模式已勾選；合成 `group.xlsx` 顯示共 4 題（兩個題組各 2 子題及兩道單題），結果表具第 1–50 組欄位。釋放後從學生首頁選第 50 組，舊憑證被拒；切回教師頁讀取釋放後的新邀請碼，再輸入後重新加入成功。從重新選取第 50 組到用更新邀請碼加入成功，工具計時 18.15 秒；此段包含一次使用過期憑證的失敗嘗試。教師名單也確認第 50 組重新加入。只使用合成夾具與假金鑰。

task 4.2 仍未勾選：768 px 上一輪的完整循環約 12 秒，但本次乾淨重開後未重跑 768 px；桌面這輪計時從重新選取開始，不包含首次加入到教師釋放，因此不足以聲稱完整「找組、加入、釋放、重新加入」流程全程在 30 秒內。另 768 px 的結果表可見但需水平捲動查看後段組別。服務目前保持運行。

## 2026-11-28 Edge 768px 續驗結果

使用 Microsoft Edge DevTools Responsive viewport（768px），本機服務 `127.0.0.1:8000` 回應正常。教師端確認經典搶答模式、答題狀況與結果表格、Guided Notes 匯入區可見；組數為 50，組別清單含第 50 組，結果表格可水平捲動。學生端在釋放第 50 組後回首頁，輸入教師端更新後的邀請碼並選第 50 組，重新加入成功；量測約 1.95 秒。學生頁顯示第 50 組、準備中及合成 `group.xlsx` 的 4 題（含兩個題組題）。

## 2026-11-28 Edge 完整 50 組人工驗收

環境：Windows 11、Microsoft Edge；本機 `127.0.0.1:8000`，組數設為 50，組隊模式啟用，題目使用合成夾具 `tests/fixtures/guided-notes/group.xlsx`（共 4 題：兩個各含 2 子題的題組與兩道單題）。教師端確認結果表含第 1–50 組欄位，組隊狀態清單含第 50 組。

步驟：在學生組別選擇頁找到第 50 組並加入；教師端確認已加入後按「釋放」，確認清單回到未加入；回學生首頁，以教師端釋放後顯示的新邀請碼重新選取第 50 組，確認學生頁顯示「第50組／準備中」。每輪均從學生組別選擇頁已載入、50 組按鈕可見且可取得當前邀請碼時開始計時，至重新加入後學生頁顯示成功為止。

結果：一般桌面寬度完整流程 17.7 秒；Edge DevTools Responsive viewport 768 px 完整流程 24.1 秒，均在 30 秒內。兩輪首次加入、釋放及重新加入皆成功；768 px 教師端也確認經典搶答模式、50 組結果表、合成題目與組隊清單。結果表在 768 px 需水平捲動查看後段組別。驗收過程中曾因把邀請碼辨讀錯誤而出現一次拒絕；以教師端無障礙文字核對正確碼後，正式計時輪次皆成功，該次辨讀錯誤不納入通過輪次計時。全程只用合成資料與假金鑰。
