# csv-export — 匯出完整活動結果 CSV

檔位：**B**（使用者可見的匯出格式）｜需求：X-02｜parity：`docs/parity.md` §4 `csv-export`

## 決策摘要

1. 老師在活動結束後可下載完整結果 CSV；只使用老師 view 既有的 `board`、`teams`、`team_scores`，不新增 API 或重算順位，可被「下載內容對照結果表」證偽。
2. 每題每組固定一列，包含答案、伺服器順位、得主、判定、本題得分與活動總分；未作答組別也保留，可被「未作答組別仍有列」證偽。
3. UTF-8 BOM、CRLF、標準 CSV 引號跳脫；答案以試算表安全文字輸出，可被含逗號、雙引號、換行與公式前綴的輸入測試證偽。

**驗收矩陣**：`eval/acceptance/matrix.yaml` 新增 M-034。

**merge 三問第三問**：X-02 明列 CSV 活動結果匯出；不加依賴、不改伺服器或學生資料路徑，直接滿足選做需求。

## 邊界

- 只在活動 `ended` 後提供按鈕。
- CSV 欄位：題號、組別、答案、順位、是否得主、判定結果、本題得分、活動總分。
- 檔名為 `<來源檔名>_活動結果.csv`；此卡不新增 API 契約。
