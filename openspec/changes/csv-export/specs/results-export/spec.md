# 結果匯出 Specification

## Purpose

老師可將完整活動結果下載為可用試算表開啟的 CSV，以符合 X-02。

## ADDED Requirements

### Requirement: 老師可下載完整活動結果 CSV

系統 MUST 在活動結束後提供 CSV 下載，活動結束前 MUST NOT 啟用下載。CSV MUST 對每一道題目及每一組輸出一列，欄位依序為題號、組別、答案、順位、是否得主、判定結果、本題得分、活動總分。未作答的組別 MUST 保留列，答案與順位留空、本題得分為 0。順位、得主、判定、本題得分及活動總分 MUST 使用老師 view 中伺服器產生的值，不得由前端重算。

CSV MUST 以 UTF-8 BOM、CRLF 編碼，並遵循 CSV 引號跳脫。題組答案 MUST 保留子題標籤；答案以試算表公式前綴開頭時 MUST 以文字匯出。檔名 MUST 為來源名稱加 `_活動結果.csv`。

#### Scenario: 匯出所有題目與組別

- **WHEN** 活動已結束，且部分題目有多組作答、部分組別未作答
- **THEN** 每個題目與每個組別皆有一列，匯出值與老師結果表一致，未作答組別答案與順位空白且得分為 0

#### Scenario: 匯出題組與判定結果

- **WHEN** 活動使用題組，或老師已判定答案
- **THEN** 答案包含子題標籤，判定結果及得分與結果表相同

#### Scenario: 未結束不可匯出

- **WHEN** 活動尚未結束
- **THEN** CSV 下載按鈕停用或不存在

#### Scenario: CSV 文字安全與跳脫

- **WHEN** 答案含逗號、雙引號、換行或公式前綴
- **THEN** CSV 欄位保持完整，公式前綴答案以文字匯出
