## MODIFIED Requirements

### Requirement: 最快送出的組別為該題搶答成功者

每題的順位 MUST 依伺服器接收並記錄的先後決定，MUST NOT 採信客戶端時間。經典搶答模式下，順位最前且未被老師判錯的組別 MUST 為該題搶答成功者：老師未檢查時 MUST 為順位 1；搶答結束後老師判錯時 MUST 依順位遞補下一組，判對 MUST 鎖定該組；全部判錯 MUST 無搶答成功者。需老師判定對錯的模式下，搶答成功者 MUST 為依順位最早被判正確的組別（見 game-modes）。

#### Scenario: 先送出者得題
- **WHEN** 經典模式下第2組先、第1組後送出第 1 題
- **THEN** 第 1 題的搶答成功者 MUST 為第2組

#### Scenario: 並發送出
- **WHEN** 四組同時送出同一題
- **THEN** 恰一組 MUST 為順位 1，四組的順位 MUST 為 1 到 4 且不重複

#### Scenario: 判定模式取最早的正確答案
- **WHEN** 只計對錯模式下第1組先送出被判錯誤、第2組後送出被判正確
- **THEN** 第 1 題的搶答成功者 MUST 為第2組

#### Scenario: 經典搶答結束後判錯遞補
- **WHEN** 經典模式結束後，第 1 題順位 1 的第2組被老師判錯
- **THEN** 第 1 題的搶答成功者 MUST 為順位 2 的組別，第2組該題 MUST 得 0 分

#### Scenario: 全部判錯無得主
- **WHEN** 經典模式結束後，第 1 題所有送出的組別都被判錯
- **THEN** 第 1 題 MUST 沒有搶答成功者，所有組別該題 MUST 得 0 分
