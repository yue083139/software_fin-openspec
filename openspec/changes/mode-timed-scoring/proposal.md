# mode-timed-scoring — 時間計分模式：逐題開放、伺服器計時、每題揭曉後排行榜（v1.1）

檔位：**S**（搶答判定口徑、作答隔離、活動階段狀態機、`contracts/`）｜主人：@yue083139｜parity：`docs/parity.md` §4 `mode-timed-scoring`｜需求：X-04（TRD M2、T-04、T-05 時限、§6 排行榜裁定）｜依賴：`question-settings`

## 首屏決策摘要

1. **逐題開放，同一時間至多一題「進行中」**：老師按「開放下一題」依題號順序開放；該題到時限由伺服器關閉，老師也可提早結束；只收開放中那一題的送出／代價：失去「各組自選題目」的紙本感（經典與只計對錯模式保留）／屬取捨，理由：作答秒數必須有共同起點（T-04），全部同時開放時「開題時刻」對每題都一樣，速度分只反映題目順序。**另一代價（v1.1，紅隊）**：系統不送題目文字，學生手上的紙本學習單從一開始就看得到全部題目，可事先備好答案、開題瞬間送出，此時速度分量到的是「誰先備好」；學生頁只顯示進行中那一題的輸入欄，但無法阻止在系統外預備。屬取捨，呈負責人：建議老師在時間計分活動前不先發學習單，或改用經典／只計對錯模式；開題時顯示題目文字需解析題目欄，列 followup。
2. **作答秒數＝伺服器收到送出時的單調時鐘 − 該題開放時的單調時鐘；逾時（> 時限）送出 409**：客戶端時間一律不用；計時器只負責推送「已關閉」，截止判斷在送出路徑上以時鐘比對，計時器晚到也不會多收／可被假時鐘測試證偽（時限 20 秒、時鐘 20.001 秒時送出 ⇒ 409）。
3. **不採「全員送出即關閉」**：提早關閉會讓學生推知他組都已送出（作答隔離），故只有時限與老師兩種關閉方式（TRD M2 同批修訂）。
4. **計分＝`floor(1000 × (1 − t ÷ T ÷ 2) + 0.5) × 倍率`，以整數運算 `(2001 × T − 作答毫秒) // (2 × T)` 實作；t ≤ 0.5 秒得 1000 × 倍率，錯誤或未作答 0**：不用 Python `round`（銀行家捨入，探針 `round(2.5)=2`），也不用浮點（v1.1 紅隊窮舉：T 為 5–120 秒、毫秒為單位時浮點寫法有 5129 例少 1 分，如 T＝5、t＝1.285 應 872 得 871；整數式 0 例）／可被 TRD §4 三案例與「點五」案例證偽（t＝0.4 ⇒ 1000；t＝T ⇒ 500；T＝30、t＝2 ⇒ 967；T＝5、t＝1.285 ⇒ 872）。
5. **每題「關閉 → 老師判定 → 揭曉」；揭曉後學生看到本組該題對錯、得分與累積分數，以及全部組別的累積名次（不含他組分數）；他組答案與分數只在 `ended` 才看得到**：負責人 2026-11-12 裁定「每題揭曉後公開累積排名」（TRD §6）。v1.1（兩通道同抓）：分數是作答秒數的單調函數，公開他組分數時學生把前後兩次排行榜相減即可反推他組秒數（時限 20 秒時解析度約 0.04 秒）與答對先後，故只公開名次／代價：名次變化仍可推知他組本題大致對錯與相對快慢（屬裁定代價）／可被「揭曉後 A 組 payload 不含 B 組答案與分數」負例證偽。

**v1.1（提案輪評審）**：整數計分式；學生排行榜只列名次；計時器改迴圈（Windows 計時器可能提早約 15.6 毫秒醒來，單次睡眠會漏關）；送出路徑只讀一次時鐘；view 的 `mode` 增 `sequential`；補 `results-view` MODIFIED（時間計分在結束前就有本組結果與名次）；`question-settings` 本體放寬為語意補充。

**矩陣落點**：新增 M-014（時間計分公式）、M-015（逐題開放與伺服器截止）、M-016（揭曉後排行榜且答案仍隔離）；M-004 守門擴充時間計分模式。

**merge 三問第三問**：需求證實——X-04；負責人點名「時間計分」並裁定列入第二期。

## 目標

- `modes.py`：`Mode.sequential`、`timed` 模式；`scoring.py`：`QuestionAttrs.time_limit`、`TimedRule`、`timed_points`。
- `Activity`：`rounds`、`open_next`、`close_question`、`close_due`、`reveal_question`；送出、判定、結束在逐題模式下的前置條件；計時器任務；可注入時鐘。
- API：`/open-next`、`/close-question`、`/reveal-question`；`question-settings` 增 `time_limit`；view 增 `round`、學生 `revealed`、`leaderboard`。
- web：老師逐題控制與倒數、時限設定；學生只見進行中題目、倒數、揭曉結果與排行榜。

## 邊界（本卡不做）

全員送出即關閉（見決策 3）、答題連勝加分（Kahoot Answer Streak）、亂序出題、跨活動排行榜。
