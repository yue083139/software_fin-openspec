# game-modes Specification

## Purpose
老師在準備階段選擇遊戲模式（經典搶答、只計對錯、時間計分），以及需要判定的模式在揭曉前由老師逐筆判定正確／錯誤、參考答案只用於預填建議且永不送往學生端的規則。

## Requirements

### Requirement: 老師可在準備階段選擇遊戲模式

系統 MUST 提供「經典搶答」（預設）、「只計對錯」與「時間計分」三種模式；老師 MUST 只能在 `preparing` 階段切換模式，重置活動 MUST 保留目前模式。所有使用者的畫面 MUST 顯示目前模式名稱。

#### Scenario: 切換為只計對錯
- **WHEN** 老師在準備階段選擇「只計對錯」
- **THEN** 老師與學生畫面 MUST 顯示模式「只計對錯」

#### Scenario: 搶答中不可切換
- **WHEN** 老師在 `answering` 階段要求切換模式
- **THEN** 伺服器 MUST 回 409，模式 MUST 不變

#### Scenario: 未知模式
- **WHEN** 老師要求切換為不存在的模式
- **THEN** 伺服器 MUST 回 422

#### Scenario: 經典搶答行為不變
- **WHEN** 模式為經典搶答，且老師在結束後沒有檢查任何題
- **THEN** 送出、順位、結果與匯出 MUST 與第一期行為相同

#### Scenario: 經典搶答結束後的檢查只改得主
- **WHEN** 模式為經典搶答，老師在結束後判錯某題順位 1
- **THEN** 送出與順位 MUST 不變，該題得主、分數與匯出 MUST 依 buzz-answering 遞補

### Requirement: 只計對錯模式由老師判定每筆送出

只計對錯模式下，老師結束搶答後階段 MUST 進入 `judging`；老師 MUST 能把每一筆送出標為正確或錯誤並可改判；尚有未判定的送出時 MUST NOT 能揭曉；全部判定後老師揭曉，階段 MUST 變為 `ended`。

#### Scenario: 結束後進入判定
- **WHEN** 只計對錯模式下老師結束搶答
- **THEN** 階段 MUST 變為 `judging`

#### Scenario: 未判定完不得揭曉
- **WHEN** 判定中仍有 1 筆送出未判定，老師按揭曉
- **THEN** 伺服器 MUST 回 409，訊息 MUST 指出未判定筆數，階段 MUST 維持 `judging`

#### Scenario: 判定中不可用結束搶答繞過
- **WHEN** 判定中老師呼叫結束搶答
- **THEN** 伺服器 MUST 回 409，階段 MUST 維持 `judging`

#### Scenario: 判定不存在的送出
- **WHEN** 老師判定一個沒有送出該題的組別
- **THEN** 伺服器 MUST 回 404

### Requirement: 只計對錯模式的計分與得主

只計對錯模式下，每筆判定正確的送出 MUST 得 1 分，錯誤 MUST 得 0 分；每題得主 MUST 為依伺服器接收序最早的正確送出，無人答對 MUST 無得主；匯出 MUST 寫回得主答案。

#### Scenario: 第一個錯、第二個對
- **WHEN** 第 1 題第1組先送出且被判錯誤、第2組後送出且被判正確
- **THEN** 第 1 題得主 MUST 為第2組，第2組 MUST 得 1 分、第1組 0 分，匯出 MUST 寫回第2組答案

#### Scenario: 全部答錯
- **WHEN** 某題所有送出都被判錯誤
- **THEN** 該題 MUST 無得主，匯出 MUST 不改該題作答格

### Requirement: 參考答案只產生判定建議

匯入檔若有參考答案欄，系統 MUST 為每筆送出產生判定建議（各子題正規化後與參考答案全等為正確、否則錯誤；該題缺參考答案則無建議）；建議 MUST NOT 自動成為判定，只有老師按「採用全部建議」時才寫入**尚未判定且有建議**的送出。參考答案與建議 MUST NOT 出現在任何送往學生的訊息與回應。

#### Scenario: 採用全部建議
- **WHEN** 判定中有 3 筆未判定、其中 2 筆有建議，老師按「採用全部建議」
- **THEN** 那 2 筆 MUST 依建議判定，另 1 筆 MUST 仍未判定

#### Scenario: 不覆蓋老師已判定者
- **WHEN** 老師已把某筆判為正確而建議為錯誤，再按「採用全部建議」
- **THEN** 該筆 MUST 維持正確

#### Scenario: 學生看不到參考答案
- **WHEN** 匯入含參考答案欄的檔案並走完準備、搶答、判定、結束四個階段
- **THEN** 學生收到的所有內容 MUST NOT 含任何參考答案文字
